# Code of conduct

Kindling follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be kind and patient. Many people here are writing their first game or their first pull request.
- Critique code and ideas, never people.
- No harassment, insults, or unwelcome attention, in any space of this project.
- Assume good intent, and ask before assuming.

## Reporting

If something happens that breaks this code, report it privately to the maintainer through GitHub (the maintainer's profile, or GitHub's **Report content** option on the comment or issue). Reports are handled confidentially. The maintainer may remove content, warn, or ban, following the enforcement guidelines of the Contributor Covenant.
