3. Sprites and animation

A sprite sheet is many small pictures in one image. An animation is a list of frame numbers played at a fixed speed.

  • Frame being shown
  • Frame grid

What to notice

  • Frames are numbered left to right. run is just [2, 3, 4, 5].
  • Animation speed is in frames per second and independent of the game's update rate.
  • Flipping is a negative scale: one set of art faces both ways.

The code

const sheet = createSpriteSheet(image, 16, 16);
const run = createAnimation([2, 3, 4, 5], 10);   // frames, frames per second

// each update step
run.update(stepSeconds);

// each draw
sheet.draw(context, run.frame(), x, y, { flipX: facingLeft });
