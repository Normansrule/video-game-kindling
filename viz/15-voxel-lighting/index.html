15. Lighting a block world

Block games use plain cubes and tiny textures. What makes them look good is light. Switch each effect off and on and see what it does. Drag to turn the island; scroll or pinch to zoom.

What to notice

  • Ambient occlusion darkens creases where blocks meet. Turn it off and the hills go flat, like cardboard.
  • Shadows tell you where things are: a tree floating above the grass and a tree standing on it look the same without one.
  • Fog hides where the world ends and gives distance a color, which your eye reads as depth.
  • Drag the sun to 0.75 for a sunset: the sun light turns orange and the fog glows toward it. At night the lanterns take over.

The code

const renderer = createWorldRenderer(screen);
renderer.setWorld(world);
renderer.settings.shadows = true;
renderer.settings.ambientOcclusion = 1;   // 0 to 1
renderer.settings.fogDensity = 0.011;
renderer.settings.timeOfDay = 0.38;        // 0.25 sunrise, 0.5 noon, 0.75 sunset
renderer.render(camera, time);
