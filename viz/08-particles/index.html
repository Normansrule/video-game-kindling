8. Particles

Particles are tiny dots that live for a moment. Click or tap the picture to move the emitter. Try the presets, then tune them.

  • Emitter
  • Particles alive (see readout)

What to notice

  • Every particle comes from a fixed pool. When the pool is full, new ones are skipped instead of slowing the game.
  • Gravity pulls particles down; a negative value makes fire and smoke rise.
  • Most of the look comes from size over life and fading out. Try size end bigger than size start for smoke.

The code

import { createParticles, presets } from "kindling/2d/particles.js";

const particles = createParticles(500);
particles.emit({ ...presets.explosion, x: enemy.x, y: enemy.y });

particles.update(stepSeconds);   // update
particles.render(context);       // draw
