2. Easing: shaping motion over time

An easing function takes progress t from 0 to 1 and bends it. Same start, same end, very different feel.

  • Chosen easing
  • Linear, for comparison

What to notice

  • Out easings start fast and settle: use them for things arriving (menus, pickups popping up).
  • In easings start slow and speed up: use them for things leaving.
  • Back and elastic go past 1 for a moment. That overshoot is what makes UI feel springy.

The code

import { easeOutBack } from "kindling/math/easing.js";
import { lerp } from "kindling/math/scalar.js";

const t = elapsed / duration;            // 0..1
x = lerp(startX, endX, easeOutBack(t));

// or let the engine do it:
game.tweens.to(menu, { y: 40 }, 0.6, easeOutBack);
