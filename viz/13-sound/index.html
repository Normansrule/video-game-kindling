13. Sound effects from code

No sound files: a wave whose pitch slides, shaped by a volume envelope. Move the sliders, press Play, and copy the line of code when you like it.

  • Pitch
  • Volume
  • The wave

Your sound as code

What to notice

  • Rising pitch sounds happy or upward (jump, power-up). Falling pitch sounds like damage or losing.
  • Square waves sound buzzy and retro, sine waves soft, sawtooth harsh, noise like hiss or explosions. Watch the wave's shape change.
  • A tiny attack (1 to 5 ms) makes a click at the start: good for hits. A long attack makes a sound swell in softly.
  • Pitch slides on an exponential curve because our ears hear ratios: 220 to 440 Hz sounds as big a jump as 440 to 880 Hz.

The code

import { createAudio } from "kindling/audio/audio.js";
import { playTone, playSfx } from "kindling/audio/sfx.js";

const audio = createAudio();     // unlocks itself on the first click or key
playSfx(audio, "coin");          // a preset
playTone(audio, { type: "square", frequency: 220, frequencyEnd: 660, duration: 0.15 });
