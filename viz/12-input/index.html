12. Input: held, pressed, released

Hold or tap Space (or click the timeline). Each column is one game step. Slow the steps down and tap fast: isDown() can miss a tap entirely, wasPressed() never does.

  • Held during the step
  • Pressed since last step
  • Released since last step

What to notice

  • A normal press lights up pressed for exactly one step, then held until you let go. That one step is when a jump should start.
  • At 2 to 5 steps per second, tap quickly. The tap lands between two steps: held stays empty but pressed still lights up. Games that only check isDown() eat button presses.
  • Everything is cleared in endStep(), which the game calls after each step. That is why "pressed" means "since the last step", not "since the last frame".
  • Keyboard, mouse and gamepad all feed one action, jump. Your game code never asks which device was used.

The code

import { createActions } from "kindling/input/actions.js";

const actions = createActions({ jump: ["Space", "mouse:0", "pad:A"] }, { keyboard, mouse, gamepad });
// in update():
if (actions.wasPressed("jump") && player.onGround) player.velocityY = -JUMP_SPEED;
// after update():
actions.endStep();
