4. Collision: boxes and circles

Drag the shapes (or focus the picture and use the arrow keys). When they overlap, the arrow shows the smallest push that separates them.

  • Shape A (you move it)
  • Shape B
  • Overlapping
  • Push-out vector and resolved position

What to notice

  • Box vs box: the push is always straight left, right, up or down, along whichever side overlaps least.
  • Circle vs circle: the push points from one center to the other.
  • Circle vs box: find the closest point on the box to the circle's center (the small dot). If it's inside the circle, they touch.

The code

import { rectPushOut } from "kindling/2d/collision.js";

const push = rectPushOut(player, wall);   // null if not touching
if (push) {
  player.x += push.x;
  player.y += push.y;
}
