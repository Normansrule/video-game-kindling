1. The fixed-timestep game loop

The screen redraws whenever it likes. The game updates in equal, fixed steps. An accumulator connects the two.

  • Frame drawn (screen refresh)
  • Update step (fixed size)

What to notice

  • Set the update rate lower than the frame rate: some frames run zero updates. The top ball stutters; the blended ball stays smooth.
  • Add jitter: frames arrive unevenly, but update steps stay perfectly even. That is why physics behaves the same on every computer.
  • The accumulator fills with real time and empties one step at a time. What's left over, divided by the step, is alpha.

The code

accumulator += frameSeconds;
while (accumulator >= step) {
  update(step);            // always the same size
  accumulator -= step;
}
render(accumulator / step); // alpha: 0..1 between two steps
