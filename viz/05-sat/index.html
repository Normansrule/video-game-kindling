5. SAT: the Separating Axis Theorem

Two convex shapes are apart if you can find one direction where their shadows don't overlap. You only need to test the directions at right angles to each edge.

  • Polygon A and its shadow
  • Polygon B and its shadow
  • Gap found: separated
  • Shadows overlap

What to notice

  • Step through the axes. If ANY axis shows a gap, the shapes are apart, no matter what the others say.
  • If every axis overlaps, they touch. The axis with the smallest overlap gives the push-out direction.
  • A box has only 2 unique axes; a triangle has 3. More edges means more axes to test.

The code

import { createBoxPolygon, polygonsCollide } from "kindling/2d/sat.js";

const ship = createBoxPolygon(20, 10, x, y, angle);
const rock = createBoxPolygon(30, 30, rockX, rockY, rockAngle);
const hit = polygonsCollide(ship, rock);  // null, or { depth, normal }
if (hit) {
  ship.x += hit.normal.x * hit.depth;
  ship.y += hit.normal.y * hit.depth;
}
