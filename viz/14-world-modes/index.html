14. One world, four views

The world is one array of numbers. Each picture below is a different function that reads the same array. Build or dig, and all four change, because there is only one world.

What to notice

  • Build a tower: the map shows a lighter square, the diorama a column, the raycaster a wall, and the 3D view casts its shadow.
  • The game code (the explorer walking around) never asks which view is on screen. That is the whole trick: keep the game in data and draw it at the end.
  • The world is about one byte per block. The views are where all the work is.

The code

import { createWorldView } from "kindling/views/world-view.js";

const view = createWorldView({ container: "#stage", world, mode: "iso" });
view.render(player, time);   // every frame
view.setMode("3d");          // any time
