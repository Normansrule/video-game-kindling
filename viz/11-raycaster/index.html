11. The raycaster

One ray per screen column. Where it hits a wall, draw a stripe whose height is 1 / distance. Left: the map from above. Right: what the player sees.

  • Player
  • Rays
  • Walls

What to notice

  • Turn off the fisheye fix: straight walls bulge, because rays at the edge travel farther than rays in the middle.
  • Use fewer rays: the 3D view turns into wide blocky stripes. Each stripe is one ray.
  • Walls facing one way are drawn darker. That one rule makes corners readable.

The code

import { castRays, drawRaycastView } from "kindling/3d/raycaster.js";

const hits = castRays(MAP, player, fieldOfView, screenWidth);
drawRaycastView(context, hits, screenWidth, screenHeight);
