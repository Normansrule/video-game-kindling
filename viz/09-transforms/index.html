9. 3D transforms: model, view, projection

Every corner of every object is multiplied by three matrices: model (place the object), view (move the world in front of the camera) and projection (flatten 3D onto the screen). Drag the picture to orbit.

  • x axis (right)
  • y axis (up)
  • z axis (toward you)

The model matrix right now

What to notice

  • Rotate, then move: order matters. The model matrix here is translate x rotate x scale, read right to left: scale first, then rotate, then move.
  • Narrow the field of view and the cube looks flatter, like a zoom lens. Widen it and the edges stretch.
  • The bottom row of the model matrix is always 0, 0, 0, 1. The right column is where the object is.

The code

import * as mat4 from "kindling/math/mat4.js";

let model = mat4.translation(x, y, z);
model = mat4.rotateY(model, angleY);
model = mat4.scale(model, { x: s, y: s, z: s });

renderer.begin(camera, light);          // sets view + projection
renderer.drawMesh(cubeMesh, model, { texture });
