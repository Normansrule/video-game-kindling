6. Arcade physics

Gravity changes velocity, velocity changes position, and solids stop you. Move with the arrow keys or A and D, jump with Space or W, or use the buttons.

  • Player body
  • Velocity arrow
  • Solid
  • One-way platform

What to notice

  • Movement is done one axis at a time: first x, then y. That is why you slide along walls instead of sticking.
  • Jump up through the green platform from below, then land on it. One-way platforms only collide when you are falling onto them.
  • Turn bounce to 1 and the balls never lose energy. Turn it to 0 and they stop dead.

The code

import { createBody, moveAndCollide } from "kindling/2d/physics.js";

const player = createBody({ x: 40, y: 0, width: 12, height: 14, gravity: 900 });

// each update step
player.velocityX = actions.axis("left", "right") * 120;
if (actions.wasPressed("jump") && player.onGround) player.velocityY = -320;
moveAndCollide(player, stepSeconds, level);   // level = tilemap or createSolids([...])
