7. Tilemaps and the camera

The level is a grid of characters. The camera decides which part of it you see, follows the player smoothly and never shows outside the level.

  • Player
  • Camera view
  • Dead zone
  • Tiles checked for collision

What to notice

  • Inside the dead zone the camera doesn't move. That stops the screen from jittering on every small step.
  • Smoothing 0 snaps the camera to the target. Higher values ease it toward the target (it never overshoots).
  • Collision only checks the few red tiles under the player, never the whole map. That is why grids are fast.

The code

const level = createTilemap({ tileSize: 16, rows: LEVEL_ROWS, solid: "#" });
const camera = createCamera({ width: 320, height: 180, smoothing: 8,
  deadZone: { width: 40, height: 30 },
  bounds: { x: 0, y: 0, width: level.width, height: level.height } });

camera.follow(player, stepSeconds);    // update
camera.begin(context);                 // draw world here
level.draw(context, drawTile, camera.view());
camera.end(context);
