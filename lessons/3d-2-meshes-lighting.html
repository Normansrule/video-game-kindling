Meshes and lighting

3D track · lesson 2 of 4 · about 35 minutes

A mesh is triangles plus a little extra data per corner. Lighting is three simple terms added together.

1 The idea

A mesh stores, for each corner: a position, a normal (an arrow pointing straight out of the surface) and a texture coordinate (UV: which part of the image goes here). Then a list of indices says which three corners make each triangle. Kindling uploads this to the GPU once, then draws it as often as you like.

Phong lighting adds three terms per pixel:

  • Ambient: a little light everywhere, so shadows are not pure black.
  • Diffuse: how directly the surface faces the light: the dot product of the normal and the direction to the light. Facing it: bright. Edge on: dark.
  • Specular: the shiny highlight, where light bounces straight toward your eye. Higher shininess means a smaller, sharper spot.

2 See it

Switch each term on and off, and move the shininess slider. Notice that diffuse alone already reads as "3D".

Open it in its own tab (easier on a phone).

3 Walkthrough

  1. Primitives return plain data; createMesh uploads it. A low segment count gives a low-poly look: 
    const rockMesh = createMesh(gl, sphere(0.5, 10, 6));
const treeMesh = createMesh(gl, parseOBJ(await loadText("./tree.obj")));   // or load a model file
  2. The diffuse term in the fragment shader (engine/3d/lighting.js) is one line: 
    float diffuse = max(dot(normal, toLight), 0.0);
  3. Specular uses the light's reflection and the direction to the eye: 
    vec3 bounced = reflect(-toLight, normal);
float specular = 0.0;
if (diffuse > 0.0) specular = pow(max(dot(bounced, toCamera), 0.0), u_shininess);
  4. In game code you never touch the shader. You set a light once per frame and give each mesh a material: 
    renderer.begin(camera, { position: [5, 8, 5], color: [1, 1, 1], ambient: 0.3 });
renderer.drawMesh(rockMesh, model, { color: [0.55, 0.55, 0.58], specularStrength: 0.08, shininess: 8 });
  5. One mesh, many objects: the lit-scene sample draws 40 trees with one tree mesh and 40 different model matrices.

4 Exercise

Make a new 3D page that shows a row of 8 red spheres with shininess 2, 4, 8, … 256 (and specularStrength: 1), lit by a light that slowly circles above them. It is the best way to learn what shininess looks like.

Hint 1

Start from the quick example in docs/modules/3d.md. A scene can have only a render method.

Hint 2

Math.pow(2, i + 1) for i from 0 to 7 gives 2 to 256. Put sphere i at x = -3.5 + i.

Solution

One way to do it (yours can be different and still right):

import { createGame } from "kindling/game.js";
import { createRenderer } from "kindling/3d/renderer.js";
import { createMesh } from "kindling/3d/mesh.js";
import { sphere } from "kindling/3d/primitives.js";
import { createOrbitCamera } from "kindling/3d/camera3d.js";
import * as mat4 from "kindling/math/mat4.js";

const game = createGame({ webgl: true, width: 640, height: 360 });
const renderer = createRenderer(game.screen);
const ball = createMesh(game.gl, sphere(0.4, 32, 16));
const camera = createOrbitCamera({ distance: 7, pitch: 0.3 });

game.scenes.add("view", {
  render(game) {
    const t = game.time.elapsed * 0.6;
    renderer.begin(camera, { position: [Math.cos(t) * 5, 4, Math.sin(t) * 5], color: [1, 1, 1], ambient: 0.2 });
    for (let i = 0; i < 8; i++) {
      const shininess = Math.pow(2, i + 1);
      renderer.drawMesh(ball, mat4.translation(-3.5 + i, 0, 0), { color: [0.9, 0.3, 0.2], specularStrength: 1, shininess });
    }
  },
});
game.start("view");
