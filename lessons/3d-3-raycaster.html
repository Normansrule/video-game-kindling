The raycaster: 3D without WebGL

3D track · lesson 3 of 4 · about 30 minutes

In 1992 Wolfenstein 3D ran on computers with no 3D hardware. The trick fits in a hundred lines.

1 The idea

The world is a flat grid of walls, like a tilemap. The player has a position and an angle. For every column of the screen, cast a ray from the player across the grid until it hits a wall. Draw a vertical stripe in that column: tall if the wall is near, short if it is far. Height = 1 / distance.

Rays step from grid line to grid line (the DDA, digital differential analyzer, method), so even long corridors take only a few steps per ray. One fix is needed: rays at the edge of the view travel further to reach a flat wall than rays in the middle, which makes walls bulge (the fisheye effect). Measuring distance at right angles to the camera instead of along the ray removes it.

3 Walkthrough

  1. The whole view in two calls, from the maze sample: 
    const hits = castRays(grid, player, FIELD_OF_VIEW, WIDTH / 2);   // one ray per 2 pixels
drawRaycastView(context, hits, WIDTH, HEIGHT, { wallColors: WALL_COLORS, shadeDistance: 9 });
  2. The fisheye fix inside castRays: multiply by the cosine of the angle between this ray and the center of the view. 
    const hit = castRay(grid, player.x, player.y, rayAngle);
if (hit && fixFisheye) hit.distance = hit.distance * Math.cos(rayAngle - player.angle);
  3. Walking: forward is along the view angle, sideways is 90 degrees to it, and moveInGrid slides along walls one axis at a time (the same idea as 2D physics): 
    moveInGrid(grid, player, cos * forward - sin * sideways, sin * forward + cos * sideways);
  4. The maze itself is generated with a recursive backtracker (generateMaze): walk randomly, knock down walls, and back up at dead ends. Every run is a new maze with exactly one path between any two places.

4 Exercise

Give the raycaster maze a best time that survives closing the browser. Show it on the "YOU ESCAPED!" screen, and say "New best!" when you beat it.

Hint 1

createStorage("raycaster-maze") from kindling/core/storage.js gives save(key, value) and load(key, fallback).

Hint 2

Check and save where the sample detects the exit (where mazesSolved += 1 happens), and remember whether it was a new best in a variable for the escaped screen.

Solution

One way to do it (yours can be different and still right):

import { createStorage } from "kindling/core/storage.js";
const storage = createStorage("raycaster-maze");
let bestSeconds = storage.load("bestSeconds", null);
let newBest = false;

// Where the exit is reached, next to mazesSolved += 1:
newBest = bestSeconds === null || seconds < bestSeconds;
if (newBest) {
  bestSeconds = seconds;
  storage.save("bestSeconds", bestSeconds);
}

// In the "escaped" scene's render, under the time line:
text(context, newBest ? "New best!" : "Best " + bestSeconds.toFixed(1) + " s", WIDTH / 2, 140, { align: "center", color: "#ffd23f" });
