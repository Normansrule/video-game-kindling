Game feel

Game design track · lesson 2 of 3 · about 25 minutes

Game feel is how an action feels in your hands. It comes from timing and reaction, not from features.

1 The idea

Players judge a game in seconds, by how it responds. Four ingredients:

  • Response: input acts on the very next step. Buffers and coyote time forgive near-misses, because players press early and late all the time.
  • Easing: things accelerate and settle instead of starting and stopping instantly. approach() for speeds, damp() for cameras, easing curves for UI (user interface) motion.
  • Reaction: every action gets a sound, a particle, a shake or a flash. (See Juice.)
  • Squash and stretch: objects deform a little when they jump and land. Animators have used it for a century because it reads as weight.

2 See it

Compare the curves. easeOutCubic feels responsive (fast start, soft stop); easeOutBack overshoots, which is great for things that pop in.

Open it in its own tab (easier on a phone).

3 Walkthrough

  1. Acceleration and friction in the platformer: the player reaches full speed quickly but not instantly, and slides a tiny bit when you let go. 
    player.velocityX = approach(player.velocityX, direction * RUN_SPEED, ACCELERATION * stepSeconds);
// no input:
player.velocityX = approach(player.velocityX, 0, FRICTION * stepSeconds);
  2. A camera that eases with damp (the same at any frame rate) and a dead zone, so small moves do not shake the view: 
    createCamera({ width: 320, height: 180, smoothing: 10, deadZone: { width: 24, height: 40 } });
  3. Pop-in with overshoot, from Breakout: 
    game.tweens.to(brick, { scale: 1 }, 0.4, easeOutBack);
  4. Sound with a little random pitch so a repeated action never sounds identical: playSfx(audio, "coin") varies pitch by ±5% on its own.

4 Exercise

Add squash and stretch to the platformer hero: stretch tall and thin when jumping, squash wide and short when landing, and ease back to normal.

Hint 1

Keep const squash = { x: 1, y: 1 }. On jump set { x: 0.75, y: 1.25 }, on landing { x: 1.3, y: 0.7 }, and tween back to 1 with easeOutBack.

Hint 2

Sprites scale evenly, so wrap the draw in context.save(), translate to the hero's feet, context.scale(squash.x, squash.y), draw at (0, 0), then context.restore().

Solution

One way to do it (yours can be different and still right):

import { easeOutBack } from "kindling/math/easing.js";
const squash = { x: 1, y: 1 };
function setSquash(x, y) {
  squash.x = x;
  squash.y = y;
  game.tweens.to(squash, { x: 1, y: 1 }, 0.2, easeOutBack);
}

// In updatePlayer(): in the jump block      setSquash(0.75, 1.25);
//                    where landing dust is emitted (player.onGround && !wasOnGround)   setSquash(1.3, 0.7);

// In render(), instead of the single heroSheet.draw line:
context.save();
context.translate(Math.round(player.x + 5), Math.round(player.y + 14));   // the hero's feet
context.scale(squash.x, squash.y);
heroSheet.draw(context, animator.frame(), 0, 0, { originX: 0.5, originY: 14 / 16, flipX: facingLeft });
context.restore();

Scaling around the feet (not the center) keeps the hero planted on the ground while it squashes.
