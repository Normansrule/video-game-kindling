A first-person walk

3D track · lesson 4 of 4 · about 35 minutes

Put the camera in the player's head, let the mouse turn it, and walk relative to where you look.

1 The idea

A first-person camera has a position and two angles: yaw (turning left and right) and pitch (looking up and down). The mouse changes them. Pointer lock hides the cursor and reports how far the mouse moved, so you can turn forever without hitting the edge of the screen.

Walking uses only yaw: flatForward() points where you look but along the ground, so looking up never makes you fly. The player is a 3D box that moves one axis at a time against wall boxes, exactly like 2D platformer physics with a z axis. The level is still written as text.

2 See it

Click the game to capture the mouse (Escape gives it back), then walk with WASD and find the five crystals.

Open it in its own tab (easier on a phone).

3 Walkthrough

  1. The text map becomes boxes for both drawing and collision: 
    if (letter === "#") walls.push(boxFromCenter(x, WALL_HEIGHT / 2, z, CELL, WALL_HEIGHT, CELL));
  2. Mouse look. Lock on a click; then each step turn by however far the mouse moved: 
    if (mouse.wasPressed(0) && !mouse.isLocked()) mouse.lock();
if (mouse.isLocked()) {
  const moved = mouse.movement();
  camera.look(moved.x, moved.y);
}
  3. Walk relative to the camera, then collide: 
    const forward = camera.flatForward();
const right = camera.right();
player.velocityX = (forward.x * forwardInput + right.x * sideInput) * WALK_SPEED;
player.velocityZ = (forward.z * forwardInput + right.z * sideInput) * WALK_SPEED;
moveAndCollide3D(player, stepSeconds, solids);
  4. Put the eye in the body, and fade far walls into the sky with fog: 
    camera.position.y = player.y + EYE_HEIGHT;
renderer.setFog(22);

4 Exercise

Add a sprint: while Shift (or gamepad B) is held, walk 1.7 times faster and widen the field of view a little, easing in and out so it feels like speed.

Hint 1

Add sprint: ["ShiftLeft", "pad:B"] to the actions. The camera's lens is camera.fieldOfView in radians; the default is Math.PI / 3.

Hint 2

damp(current, target, sharpness, stepSeconds) from kindling/math/scalar.js eases a value toward a target smoothly.

Solution

One way to do it (yours can be different and still right):

// actions: add   sprint: ["ShiftLeft", "pad:B"],
import { clamp, damp } from "kindling/math/scalar.js";

// In update, before setting the velocity:
const sprinting = game.actions.isDown("sprint");
const speed = sprinting ? WALK_SPEED * 1.7 : WALK_SPEED;
camera.fieldOfView = damp(camera.fieldOfView, sprinting ? 1.25 : Math.PI / 3, 8, stepSeconds);
player.velocityX = moveX * speed;
player.velocityZ = moveZ * speed;
