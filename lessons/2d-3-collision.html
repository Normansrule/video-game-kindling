Collision

2D track · lesson 3 of 6 · about 30 minutes

Two questions: are these touching, and if so, which way do I push them apart?

1 The idea

Most 2D games are made of AABBs (axis-aligned bounding boxes: rectangles that never rotate) and circles. Two boxes overlap unless one is completely left of, right of, above or below the other. Two circles overlap when the distance between their centers is less than the sum of their radii.

Detection says yes or no. Games also need resolution: the smallest move that separates the shapes. For two boxes it is whichever of the four directions (left, right, up, down) needs the shortest push. The direction tells you more than you think: pushed up means you are standing on it.

Rotated shapes need the SAT (Separating Axis Theorem), covered in its own visualization. Start with boxes; they go a very long way.

2 See it

Drag shape A around. The arrow is the push-out vector: the smallest move that gets A out of B.

Open it in its own tab (easier on a phone).

3 Walkthrough

  1. Box versus box, from engine/2d/collision.js. Read it as "not apart on x and not apart on y": 
    export function rectsOverlap(a, b) {
  return a.x < b.x + b.width && a.x + a.width > b.x &&
         a.y < b.y + b.height && a.y + a.height > b.y;
}
  2. Breakout uses the push to decide how the ball bounces: pushed sideways means it hit a side, so flip the horizontal speed. 
    const push = circleRectPushOut(ball, brick);
if (push) {
  ball.x += push.x;
  ball.y += push.y;
  if (Math.abs(push.x) > Math.abs(push.y)) ball.velocityX = -ball.velocityX;
  else ball.velocityY = -ball.velocityY;
}
  3. Pong makes the bounce angle depend on where the ball hit the paddle, which gives the player control. The middle sends it straight, the edges send it steeply: 
    const hitPosition = clamp((ballCenter - paddleCenter) / (paddle.height / 2), -1, 1);   // -1 top .. +1 bottom
const angle = hitPosition * MAX_BOUNCE_ANGLE;
const speed = Math.hypot(ball.velocityX, ball.velocityY) * BALL_SPEED_UP;              // a bit faster each hit
ball.velocityX = Math.cos(angle) * speed * direction;
ball.velocityY = Math.sin(angle) * speed;
  4. Fast objects can jump over thin ones between two steps ("tunneling"). For bullets, use rayRect(origin, direction, rect) along the path instead of checking only where the bullet ends up.

4 Exercise

Take your moving square from the last lesson and scatter 8 coins (6×6 boxes) at random positions. When the square overlaps a coin, remove the coin and add 1 to a score shown in the corner. Add one 40×40 wall in the middle that the square cannot pass through.

Hint 1

Loop over the coins backwards and use coins.splice(i, 1) to remove one, or rebuild the list with filter.

Hint 2

For the wall: after moving, const push = rectPushOut(square, wall); if (push) { square.x += push.x; square.y += push.y; }. The square needs width and height properties for this.

Solution

One way to do it (yours can be different and still right):

import { createGame } from "kindling/game.js";
import { fillRect, text } from "kindling/2d/draw.js";
import { rectsOverlap, rectPushOut } from "kindling/2d/collision.js";
import { createRandom } from "kindling/math/random.js";

const game = createGame({
  width: 320, height: 180,
  actions: { left: ["ArrowLeft", "KeyA"], right: ["ArrowRight", "KeyD"], up: ["ArrowUp", "KeyW"], down: ["ArrowDown", "KeyS"] },
});
const random = createRandom(7);
const square = { x: 20, y: 20, width: 12, height: 12 };
const wall = { x: 140, y: 70, width: 40, height: 40 };
let coins = [];
for (let i = 0; i < 8; i++) coins.push({ x: random.range(0, 314), y: random.range(0, 174), width: 6, height: 6 });
coins = coins.filter((coin) => !rectsOverlap(coin, wall));   // no coins inside the wall
let score = 0;

game.scenes.add("play", {
  update(game, stepSeconds) {
    square.x += game.actions.axis("left", "right") * 100 * stepSeconds;
    square.y += game.actions.axis("up", "down") * 100 * stepSeconds;
    const push = rectPushOut(square, wall);
    if (push) { square.x += push.x; square.y += push.y; }
    const before = coins.length;
    coins = coins.filter((coin) => !rectsOverlap(square, coin));
    score += before - coins.length;
  },
  render(game, context) {
    fillRect(context, wall.x, wall.y, wall.width, wall.height, "#5a6070");
    for (const coin of coins) fillRect(context, coin.x, coin.y, coin.width, coin.height, "#ffd23f");
    fillRect(context, square.x, square.y, square.width, square.height, "#4fa3ff");
    text(context, "coins " + score, 4, 4);
  },
});
game.start("play");
