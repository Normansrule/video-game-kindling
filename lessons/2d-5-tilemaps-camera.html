Tilemaps and the camera

2D track · lesson 5 of 6 · about 30 minutes

Write levels as text, then let a camera follow the player through a world bigger than the screen.

1 The idea

A tilemap is a grid where each character is a tile: # wall, . air, C coin, P the player start. You can see the whole level in your editor and change it in seconds, which is perfect for a jam. Collision against a grid is fast, because a body only needs to check the handful of tiles around it.

A camera is the part of the world on screen. We never move the world; we move the camera and draw everything shifted by its position. A good camera eases toward the player (smoothing), ignores small movements (a dead zone), never shows outside the level (bounds), and can shake.

2 See it

The orange box is what the camera sees. Only the tiles inside it get drawn. Change the smoothing and the dead zone.

Open it in its own tab (easier on a phone).

3 Walkthrough

  1. Spawn markers become objects, and their tiles become air, with replace: 
    const map = createTilemap({ rows: LEVEL, tileSize: 16, solid: "#B", oneWay: "=" });
const start = map.replace("P", ".")[0];
coins = map.replace("C", ".").map((tile) => ({ x: tile.x + 4, y: tile.y + 4, width: 8, height: 8 }));
  2. The camera is told the screen size and the level size, then follows the player every step: 
    const camera = createCamera({
  width: 320, height: 180,
  bounds: { x: 0, y: 0, width: map.width, height: map.height },
  smoothing: 10,
  deadZone: { width: 24, height: 40 },
});
// update():
camera.follow(player, stepSeconds);
camera.update(stepSeconds);
  3. Drawing: everything between begin and end is in world space. The tilemap only draws tiles inside camera.view(). The HUD is drawn after end, so it stays on screen. 
    camera.begin(context);
map.draw(context, drawTile, camera.view());
drawCoins(context);
drawPlayer(context);
camera.end(context);
text(context, "COINS " + coinCount, 4, 4);   // HUD
  4. The tilemap rooms sample uses the same pieces with a different camera: it snaps one room at a time, like classic adventure games.

4 Exercise

Add breakable blocks to the platformer. A B tile is solid (it already is). When the player hits one from below with their head, it turns into air, plays a sound and bursts into particles.

Hint 1

After moveAndCollide, player.touching.top is true if the head hit something.

Hint 2

The tile above the head is at column map.columnAt(player.x + player.width / 2) and row map.rowAt(player.y - 1). Use map.get and map.set.

Solution

One way to do it (yours can be different and still right):

// In updatePlayer(), right after moveAndCollide(player, stepSeconds, map):
if (player.touching.top) {
  const column = map.columnAt(player.x + player.width / 2);
  const row = map.rowAt(player.y - 1);
  if (map.get(column, row) === "B") {
    map.set(column, row, ".");
    playSfx(audio, "hit");
    camera.shake(2, 0.15);
    particles.emit({ ...presets.explosion, count: 10, x: column * 16 + 8, y: row * 16 + 8 });
  }
}
