Platformer physics

2D track · lesson 4 of 6 · about 35 minutes

Gravity changes velocity, velocity changes position, and walls stop you. Then a few small cheats make it feel great.

1 The idea

Arcade physics is simple on purpose: a body has a position, a velocity (pixels per second) and maybe gravity (pixels per second, per second). Each step, gravity is added to the vertical velocity, then velocity moves the body.

The key trick is to move one axis at a time. Move along x, and if you are now inside a wall, push back out along x. Then do the same for y. Because each move is along one axis, you always know which way to push (back the way you came), and you slide along walls instead of snagging on corners. Landing is just "pushed up while moving down", which sets onGround.

Good platformers then cheat in the player's favor: coyote time (you can still jump a moment after running off a ledge), jump buffering (a jump pressed just before landing still counts) and variable jump height (let go early for a small hop).

2 See it

Run and jump with the buttons or arrow keys, drop bouncing balls, and change gravity and jump speed. The arrows show velocity.

Open it in its own tab (easier on a phone).

3 Walkthrough

  1. The body and the world, from the platformer sample. A tilemap is a world, because it can list the solid tiles near any rectangle: 
    const map = createTilemap({ rows: LEVEL, tileSize: 16, solid: "#B", oneWay: "=" });
const player = createBody({ x: start.x + 3, y: start.y + 2, width: 10, height: 14, gravity: GRAVITY });
  2. Each step, input sets the horizontal velocity with acceleration and friction (approach moves toward a target without overshooting), then the timers decide whether to jump: 
    player.velocityX = approach(player.velocityX, direction * RUN_SPEED, ACCELERATION * stepSeconds);

coyoteTimer = player.onGround ? COYOTE_SECONDS : coyoteTimer - stepSeconds;
jumpBufferTimer = game.actions.wasPressed("jump") ? JUMP_BUFFER_SECONDS : jumpBufferTimer - stepSeconds;
if (jumpBufferTimer > 0 && coyoteTimer > 0) {
  player.velocityY = -JUMP_SPEED;   // up is negative in 2D
  jumpBufferTimer = 0;
  coyoteTimer = 0;
}
  3. Variable jump height: while rising, if jump is not held, shrink the upward speed quickly. The Math.pow(..., stepSeconds * 60) keeps it the same at any step size. 
    if (!game.actions.isDown("jump") && player.velocityY < 0) {
  player.velocityY = player.velocityY * Math.pow(JUMP_CUT, stepSeconds * 60);
}
  4. Then one call does gravity, the x move, the y move and sets onGround and touching: 
    moveAndCollide(player, stepSeconds, map);
  5. Press ` in the platformer to open the debug overlay and watch velocityY and the coyote timer change as you play.

4 Exercise

Add a double jump to the platformer: one extra jump in the air, which comes back when you land. Make the second jump a little weaker (80% of JUMP_SPEED).

Hint 1

Keep a counter airJumpsLeft. Reset it to 1 whenever player.onGround is true.

Hint 2

The normal jump needs coyote time; the air jump should happen on wasPressed("jump") when coyote time has run out and airJumpsLeft > 0.

Solution

One way to do it (yours can be different and still right):

// Near the other timers:
let airJumpsLeft = 1;

// In updatePlayer(), right after the normal jump block:
if (player.onGround) airJumpsLeft = 1;
if (game.actions.wasPressed("jump") && coyoteTimer <= 0 && airJumpsLeft > 0) {
  player.velocityY = -JUMP_SPEED * 0.8;
  airJumpsLeft -= 1;
  jumpBufferTimer = 0;          // so the buffer does not fire a third jump on landing
  playSfx(audio, "jump");
  particles.emit({ ...presets.sparkle, x: player.x + 5, y: player.y + 14 });
}

Why coyoteTimer <= 0? Without it, pressing jump once on the ground would use both jumps in the same step.
