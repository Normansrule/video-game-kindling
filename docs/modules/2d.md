# Module: 2d (drawing, sprites, animation)

**Files:** [`engine/2d/draw.js`](../../engine/2d/draw.js), [`sprite.js`](../../engine/2d/sprite.js), [`animation.js`](../../engine/2d/animation.js) · **Visualization:** [03 sprites](https://normansrule.github.io/video-game-kindling/viz/03-sprites/) · **Lesson:** [2D-2 Drawing and input](../../lessons/2d-2-drawing-input.html)

Everything 2D draws with the browser's **Canvas 2D** API. These helpers make the common calls one line each and keep the context clean (they save and restore any state they change).

Related 2D modules have their own pages: [collision](collision.md), [physics](physics.md), [tilemap](tilemap.md), [camera](camera.md), [particles](particles.md).

## draw.js

```js
import { fillRect, fillCircle, line, text, dim } from "kindling/2d/draw.js";

fillRect(context, 10, 10, 32, 8, "#ffb347");
fillCircle(context, 160, 90, 6, "white");
text(context, "SCORE 120", 8, 8, { size: 8, color: "#fff", shadow: "#000" });
text(context, "PAUSED", 160, 90, { size: 16, align: "center", bold: true });
dim(context, 320, 180, 0.6);   // darken the whole screen behind a menu
```

| Function | Notes |
|---|---|
| `fillRect`, `strokeRect(…, lineWidth)` | `x, y` is the top-left corner. |
| `fillCircle`, `strokeCircle` | `x, y` is the center. |
| `line(context, x1, y1, x2, y2, color, lineWidth)` | |
| `fillPolygon(context, points, color)` | `points` is a list of `{ x, y }`. |
| `text(context, message, x, y, { size, color, align, baseline, font, bold, shadow })` | `baseline` defaults to `"top"`, so `y` is the top of the text. `shadow: "#000"` (a color) adds a 1-pixel drop shadow that keeps text readable on any background. |
| `dim(context, width, height, amount)` | A black see-through rectangle. |

## sprite.js

A **sprite sheet** is one image holding many same-sized frames in a grid. Frame numbers go left to right, then top to bottom.

```js
const images = await loadImages({ hero: "./hero.png" });
const heroSheet = createSpriteSheet(images.hero, 16, 16);
heroSheet.draw(context, frameNumber, player.x, player.y, { flipX: player.facing < 0 });
```

`draw(context, frame, x, y, options)` options: `flipX`, `flipY`, `rotation` (radians, around the origin), `scale`, `alpha` (0 to 1), `originX`, `originY` (0 to 1; 0.5 = center). `frameRect(frame)` tells you where a frame is in the image. `drawImage(context, image, x, y, options)` takes the same options for a whole image.

For pixel art, create the game with `pixelArt: true` so the browser does not blur pixels when scaling.

## animation.js

```js
const animator = createAnimator({
  idle: createAnimation([0, 1], 2),           // frames 0 and 1, 2 frames per second
  run:  createAnimation([2, 3, 4, 5], 12),
  jump: createAnimation([6], 1, false),       // false = do not loop
}, "idle");

// in update():
animator.play(player.onGround ? (moving ? "run" : "idle") : "jump");
animator.update(stepSeconds);
// in render():
heroSheet.draw(context, animator.frame(), player.x, player.y);
```

`play(name)` does nothing if that animation is already playing, so you can call it every step. A non-looping animation stops on its last frame and reports `isFinished()`. `current()` gives the playing animation's name.

## atlas.js

### Texture atlases

A **texture atlas** is one image holding pictures of *different* sizes, plus a list of where each one is. Use it when your art isn't a neat grid of equal frames: a tree, a coin and a door in one file. Make one with the [sprite packer](https://normansrule.github.io/video-game-kindling/make/sprite-packer/).

```js
const images = await loadImages({ atlas: "./atlas.png" });
const atlas = createAtlas(images.atlas, await (await fetch("./atlas.json")).json());

atlas.draw(context, "coin", 40, 20);                          // same options as sprite sheets
const run = createAnimation(atlas.sequence("hero-run"), 12);   // "hero-run-0", "hero-run-1", ...
atlas.draw(context, run.frame(), player.x, player.y, { flipX: facingLeft });
```

`packRects(items, { maxWidth, padding, powerOfTwo })` does the packing: a **skyline** packer (each rectangle goes where its bottom edge would be lowest) that tries a range of widths and keeps the smallest result. It returns `{ width, height, frames, fits }`; `packEfficiency(packed)` says how much of the image is pictures. `drawRegion(context, image, rect, x, y, options)` in `sprite.js` draws any rectangle of an image with the usual options.

## Gotchas

- **Round positions for pixel art** (`Math.round(x)`) or sprites shimmer between pixels as they move.
- **Images load asynchronously.** `await loadImages(...)` before starting the game.
