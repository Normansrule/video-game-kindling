# Module: 3d

**Files:** [`engine/3d/`](../../engine/3d/) · **Visualizations:** [09 transforms](https://normansrule.github.io/video-game-kindling/viz/09-transforms/), [10 Phong lighting](https://normansrule.github.io/video-game-kindling/viz/10-phong-lighting/), [11 raycaster](https://normansrule.github.io/video-game-kindling/viz/11-raycaster/) · **Lessons:** [3D track](../../lessons/index.html#3d) · **Samples:** [3D-01 to 3D-05](../../samples/index.html)

Two ways to make 3D:

1. **Real 3D with WebGL 2** (Web Graphics Library, version 2): the graphics card draws triangles. Used by samples 3D-01, 02, 04 and 05.
2. **A raycaster** with plain Canvas 2D: fake 3D from a grid map, like Wolfenstein 3D (1992). Used by sample 3D-03. Simpler, and great for a jam.

## The WebGL pipeline in one picture

```text
mesh (corners, normals, texture coords, triangles)       uploaded once
   │  model matrix:      where is this object?            per object
   │  view matrix:       where is the camera?             per frame
   │  projection matrix: how does the lens squash 3D to 2D?
   ▼
vertex shader (runs per corner)  →  triangles on screen  →  fragment shader (runs per pixel: lighting, texture, fog)
```

Kindling's `createRenderer` hides the bookkeeping so a frame is:

```js
import { createGame } from "kindling/game.js";
import { createRenderer } from "kindling/3d/renderer.js";
import { createMesh } from "kindling/3d/mesh.js";
import { cube } from "kindling/3d/primitives.js";
import { createOrbitCamera } from "kindling/3d/camera3d.js";
import * as mat4 from "kindling/math/mat4.js";

const game = createGame({ webgl: true, width: 640, height: 360 });
const renderer = createRenderer(game.screen);
const cubeMesh = createMesh(game.gl, cube(1));
const camera = createOrbitCamera({ distance: 4 });

game.scenes.add("view", {
  render(game) {
    renderer.begin(camera, { position: [3, 4, 5], color: [1, 1, 1], ambient: 0.3 });
    renderer.drawMesh(cubeMesh, mat4.rotationY(game.time.elapsed), { color: [1, 0.6, 0.2] });
  },
});
game.start("view");
```

Kindling 3D uses meters, and **+y is up**. A first-person camera with yaw 0 looks down **-z**.

## Files

| File | What it gives you |
|---|---|
| `gl.js` | `createGL({ canvas, width, height, fit, clearColor })`: a WebGL 2 canvas, sharp on high-DPI screens, with depth testing and back-face culling on. `createGame({ webgl: true })` calls it for you. |
| `shader.js` | `createShaderProgram(gl, vertexSource, fragmentSource)` → `{ program, use(), set(name, value), uniforms }`. Compile errors show the line. Attribute locations are fixed: `ATTRIBUTE = { position: 0, normal: 1, uv: 2 }`. |
| `mesh.js` | `createMesh(gl, { positions, normals, uvs, indices })` → `{ draw() }`. Uploads once into a VAO (vertex array object). |
| `primitives.js` | `box(width, height, depth)`, `cube(size)`, `plane(width, depth, subdivisions, uvRepeat)`, `sphere(radius, segments, rings)`. Few segments give a low-poly look. |
| `obj.js` | `parseOBJ(text)` reads `.obj` model files (positions, normals, texture coordinates, faces; polygons become triangles). `computeNormals(data)` when a file has none. |
| `texture.js` | `loadTexture(gl, url, { pixelated, repeat })`, `createCanvasTexture(gl, size, draw)` (paint a texture with the 2D canvas API), `createCheckerTexture(gl, squares, colorA, colorB)`, `createTexture(gl, imageOrCanvas)`. |
| `camera3d.js` | `createOrbitCamera({ target, distance, yaw, pitch, fieldOfView, near, far })` with `rotate(dx, dy)`, and `createFirstPersonCamera({ position, yaw, pitch })` with `look(dx, dy)`, `forward()`, `flatForward()`, `right()`. Both give `view()` and `projection(aspect)`. |
| `lighting.js` | The Phong shaders (ambient + diffuse + specular, with fog), `defaultLight`, `defaultMaterial`. Read it: it is short and every line is commented. |
| `renderer.js` | `createRenderer(screen)` → `begin(camera, light)`, `drawMesh(mesh, model, { color, texture, specularStrength, shininess })`, `setLight(light)`, `setFog(distance, color)`, `setTerms(ambient, diffuse, specular)`. |
| `collision3d.js` | Boxes in 3D: `boxesOverlap`, `pointInBox`, `boxCenter`, `boxFromCenter`, `rayBox`, `createBody3D`, `moveAndCollide3D`. The [physics](physics.md) idea with a third axis. |
| `raycaster.js` | `castRay`, `castRays(grid, player, fieldOfView, count, fixFisheye)`, `drawRaycastView(context, hits, width, height, { wallColors, ceilingColor, floorColor, shadeDistance, wallHeight })`, `moveInGrid(grid, player, dx, dy, radius)`, `isWallAt`, `shade(color, brightness)`. |

## Phong lighting in three lines

- **Ambient:** a little light everywhere, so shadows are not pitch black.
- **Diffuse:** surfaces facing the light are brighter: `max(dot(normal, toLight), 0)`.
- **Specular:** a shiny highlight where the light bounces toward your eye. `shininess` makes it smaller and sharper.

Turn each one on and off in the [lighting visualization](https://normansrule.github.io/video-game-kindling/viz/10-phong-lighting/).

## Gotchas

- **Triangle winding:** front faces go counter-clockwise. Back faces are skipped (culling). If a model looks inside out, its winding is reversed. The tests check every primitive.
- **Normals and scaling:** non-uniform scaling bends normals; the renderer fixes this with `mat4.normalMatrix` for you.
- **HUDs in 3D** are easiest as HTML text on top of the canvas (the samples use a `<p id="hud">`).
- **Pointer lock** for mouse look needs a click first; see [input](input.md).
