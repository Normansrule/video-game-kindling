# Resources

Hand-picked, free, in English. Every link was checked when this page was last updated (see the bottom). If one breaks, please open an issue.

## Books you can read online

| Resource | Why |
|---|---|
| [Game Programming Patterns](https://gameprogrammingpatterns.com/) by Robert Nystrom | Game loop, update method, object pool, state: the patterns Kindling uses, explained beautifully. |
| [Eloquent JavaScript](https://eloquentjavascript.net/) by Marijn Haverbeke | Modern JavaScript from zero; chapter 16 builds a platformer. |
| [The Book of Shaders](https://thebookofshaders.com/) | Fragment shaders, one small step at a time. |
| [The Nature of Code](https://natureofcode.com/) by Daniel Shiffman | Vectors, forces, particles and steering, with interactive examples. |
| [The Rust Programming Language](https://doc.rust-lang.org/book/) | For the [Rust bridge](bridges/rust.md). |

## Articles and tutorials

| Resource | Topic |
|---|---|
| [Fix Your Timestep!](https://gafferongames.com/post/fix_your_timestep/) by Glenn Fiedler | The fixed-timestep loop in `engine/core/loop.js`. |
| [Collision Detection](https://www.jeffreythompson.org/collision-detection/table_of_contents.php) by Jeffrey Thompson | Every 2D shape pair, with code. |
| [N Tutorial A: Collision Detection and Response](https://www.metanetsoftware.com/technique/tutorialA.html) by Metanet | SAT (Separating Axis Theorem) explained by the makers of N. |
| [Red Blob Games](https://www.redblobgames.com/) by Amit Patel | Interactive explanations of grids, hexagons, pathfinding and noise. |
| [Raycasting](https://lodev.org/cgtutor/raycasting.html) by Lode Vandevenne | The raycaster in `engine/3d/raycaster.js`. |
| [WebGL2 Fundamentals](https://webgl2fundamentals.org/) | The WebGL 2 under `engine/3d/`, from scratch. |
| [Learn OpenGL](https://learnopengl.com/) | Transformations, lighting and cameras, explained slowly. |
| [MDN: Game development](https://developer.mozilla.org/en-US/docs/Games) | Browser game APIs (application programming interfaces) from the Mozilla Developer Network. |
| [MDN: Canvas API](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API) and [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) | The references behind `2d/` and `audio/`. |

## Free assets

Always check each asset's license and credit the author when asked. CC0 means public domain: no credit required (but it is kind).

| Resource | What |
|---|---|
| [Kenney](https://kenney.nl/assets) | Thousands of CC0 sprites, tiles, 3D models, fonts and sounds. |
| [OpenGameArt](https://opengameart.org/) | Community art and audio; licenses vary per asset. |
| [itch.io free game assets](https://itch.io/game-assets/free) | Huge, mixed licenses. |
| [Lospec palette list](https://lospec.com/palette-list) | Ready-made pixel-art color palettes. |
| [jsfxr](https://sfxr.me/) | Retro sound effects in the browser (or use Kindling's [sound visualization](https://normansrule.github.io/video-game-kindling/viz/13-sound/)). |
| [Freesound](https://freesound.org/) | Recorded sounds; check each license. |

## Tools

| Tool | What |
|---|---|
| [Aseprite](https://www.aseprite.org/) | Pixel art and animation (paid, or compile the source yourself). [LibreSprite](https://libresprite.github.io/) is a free fork. |
| [Piskel](https://www.piskelapp.com/) | Free pixel-art editor in the browser. |
| [Tiled](https://www.mapeditor.org/) | Tilemap editor (Kindling levels are text, but Tiled is great for big maps). |
| [Blender](https://www.blender.org/) | 3D modeling; export `.obj` for `parseOBJ`. |
| [Visual Studio Code](https://code.visualstudio.com/) with the [WSL extension](https://code.visualstudio.com/docs/remote/wsl) | Edit files inside WSL (Windows Subsystem for Linux) from Windows. |
