Sprite packer

Drop in PNG pictures of any size. Get one atlas image and a JSON list of where each picture is, ready for createAtlas().

No pictures yet. Try the demo sprites.

Use it in a game

Put atlas.png and atlas.json next to your main.js. Pictures named hero-run-0.png, hero-run-1.png … become an animation with sequence().

import { loadImages } from "kindling/core/assets.js";
import { createAtlas } from "kindling/2d/atlas.js";
import { createAnimation } from "kindling/2d/animation.js";

const images = await loadImages({ atlas: "./atlas.png" });
const data = await (await fetch("./atlas.json")).json();
const atlas = createAtlas(images.atlas, data);

const run = createAnimation(atlas.sequence("hero-run"), 12);
// in render:  atlas.draw(context, run.frame(), x, y, { flipX: facingLeft });
// one-offs:   atlas.draw(context, "coin", 40, 20);

How the packing works

  • Pictures are sorted tallest first, then placed one at a time.
  • The packer keeps a skyline: the outline of the tops of everything placed so far. Each picture goes where its bottom edge would be lowest, so gaps fill from the bottom up.
  • The space between pictures stops neighbours bleeding into each other when a sprite is scaled or drawn at a fractional position.
  • Some older graphics cards want power-of-two sizes (256, 512, 1024). Canvas games don't need it.
