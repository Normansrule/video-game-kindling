# Jams that suit a Kindling game

A browser game made with Kindling runs anywhere a link opens, so it fits almost every online jam. These recur regularly; check each site for the next date. **Rules change between editions:** read the current rules on pre-made engines, templates, assets, team size and AI-assisted tools before you start, and disclose AI help if the jam asks.

| Jam | Length | Notes |
|---|---|---|
| [GMTK Game Jam](https://itch.io/jam/gmtk-2025) | about 4 days | Run by Game Maker's Toolkit; one of the biggest jams on itch.io. Huge audience; a great first big jam. |
| [Ludum Dare](https://ldjam.com/) | 48 h (Compo) or 72 h (Jam) | The classic. The Compo is solo and stricter about pre-made content; the Jam is relaxed. |
| [Global Game Jam](https://globalgamejam.org/) | 48 h, once a year | In person at local sites (some online). Good for meeting people. |
| [GameDev.js Jam](https://gamedevjs.com/jam/) | about 13 days | Made for HTML5 and JavaScript games. Kindling's home turf. |
| Mini Jam (search "Mini Jam" on the [itch.io jam calendar](https://itch.io/jams)) | 72 h, every two weeks | Small, friendly, with a theme and a limitation. Perfect for practice. |
| [Brackeys Game Jam](https://itch.io/jam/brackeys-14) | 1 week | Large community jam, twice a year. |
| [Kenney Jam](https://itch.io/jam/kenney-jam-2025) | about 2 days | You must use Kenney's free assets, so art is solved for you. |
| [itch.io jam calendar](https://itch.io/jams) | any | Every jam on itch.io, filterable by date and length. |

The itch.io links above point to the most recent edition at the time of writing; the next edition has a new page, which you can find from the organizer's profile or the calendar.

## js13kGames

[js13kGames](https://js13kgames.com/) is a month-long JavaScript jam where the zipped game must be **13 kilobytes** or less. The full Kindling engine is bigger than that, so js13k is not on the main list for v1.0.0 ([DECISIONS.md](../docs/DECISIONS.md), D4). A "13k path" (copy only the few engine functions your game uses, then minify) is planned after v1.0.0.

## Picking your first jam

1. Pick one with **72 hours or more** and a **small community** (Mini Jam is ideal). Less pressure, more feedback per game.
2. Do the [design track](../lessons/index.html#design) the week before.
3. Make one practice game with `./jam/new-game.sh practice` and upload it to itch.io as a draft, so upload day holds no surprises.
