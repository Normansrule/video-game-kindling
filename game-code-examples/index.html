Game Code Examples

Every kind of code a game needs.

35 small programs, each one file, each runnable right here. Click a card to open it in the playground, change the code, and press Ctrl + Enter to see what happens.

    Run them on your own computer

    Every example is a plain file in game-code-examples/code/. Copy one into a sample folder, or into jam/, and it becomes the start of your game.

    cd ~/projects/kindling && python3 -m http.server 8000
# then open http://localhost:8000/game-code-examples/frame.html?ex=11-platformer-physics
